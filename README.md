# TechProofLab v3

Discovery-first affiliate theme inspired by novelty-product curation sites, but with an original design and a technology-only taxonomy.

## Deploy
Upload this folder to a public GitHub repository and connect it to Cloudflare Pages. The site is static and requires no server.

## SEO
See SEO-KEYWORD-MAP.md. Seed pages target commercial-intent searches such as best tech gadgets, cool tech gadgets, new tech gadgets, best tech under $50, best desk gadgets, best AI gadgets, smart home gadgets and tech gifts.

## Important
Product prices and retailer availability are placeholders in this starter. Replace them with verified current data and your actual affiliate links before publishing commercially.
